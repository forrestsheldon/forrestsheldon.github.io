# Ideas

`ideas/` is an intellectual notebook and writing backlog. Material here may consist of titles, questions, fragments, references, possible arguments, or connections; it does not need to be polished or internally complete. Preserve uncertainty and distinctive wording.

A promising idea can later acquire its own Markdown file. When an article starts becoming actual prose, it should move into `drafts/`. Only near-publication articles should be moved into their eventual site section, optionally with `draft: true`.

The loose editorial progression is:

```text
seed → idea → developing → draft → ready → published
```

These are editorial labels only, not software states.
